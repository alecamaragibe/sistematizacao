Âncora da Saúde 🌊🩺

Site institucional da clínica médica Âncora da Saúde, com foco em apresentação de serviços, equipe e contato.

🌐 Acesse o site

🔗 Clique aqui para ver o repositório no GitHub

Se você quiser hospedar este site, uma opção rápida é usar o GitHub Pages:

Vá em Settings > Pages e selecione a branch main e a pasta root. O link de acesso será algo como:

https://alecamaragibe.github.io/Sistematiza-o

📁 Estrutura

📁 assets/
├── 📁 images/           # Imagens do site
├── 📄 logo-principal-clinica.png
├── 📄 medico1.png ...   # Imagens da equipe

📄 index.html             # Página principal
📄 style.css              # Estilos customizados
📄 script.js              # Comportamentos da página

⚙️ Como executar localmente

Clone este repositório:

git clone https://github.com/alecamaragibe/Sistematiza-o.git

Acesse a pasta do projeto:

cd Sistematiza-o

Abra o arquivo index.html no navegador (pode dar dois cliques ou usar um servidor local como o Live Server no VS Code).
