# Âncora da Saúde 🌊🩺

Site institucional da clínica médica Âncora da Saúde, com foco em apresentação de serviços, equipe e contato.

🔗 [Clique aqui](https://github.com/alecamaragibe/sistematizacao) para ver o repositório no GitHub

### Como executar localmente

Clone este repositório:
```
git clone https://github.com/alecamaragibe/sistematizacao.git
```
Acesse a pasta do projeto:
```
cd sistematizacao
```
Abra o arquivo index.html no navegador (pode dar dois cliques ou usar um servidor local como o Live Server no VS Code).
